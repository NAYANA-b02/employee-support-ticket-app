# Agent Rules

Follow these rules when changing the Employee Support Ticket Management Application.

- Follow the existing project architecture and coding style.
- Use Node.js built-in modules, vanilla HTML, CSS and JavaScript.
- Avoid unnecessary dependencies.
- Do not modify unrelated files.
- Preserve existing functionality.
- Validate inputs on the server side.
- Handle errors clearly.
- Add tests for new features.
- Keep the project simple and suitable for a student demo.
- Do not add real authentication or external services.
